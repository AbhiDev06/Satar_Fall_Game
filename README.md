# 🚀 Starfall — Space Shooter Game

Starfall is a browser-based space shooting game built using **HTML, CSS, and JavaScript**. Control your spaceship, destroy enemies, survive challenging waves, and defend the galaxy!

## 🎮 Features

- Automatic spaceship shooting
- Multiple enemy types
- Increasing difficulty across waves
- Boss battles every five waves
- Score, lives, wave, and best-score tracking
- Power-ups: Rapid Fire, Shield, and Extra Life
- Pause and resume functionality
- Keyboard, mouse, and touch controls
- Best score saved using browser Local Storage
- Responsive game layout

## 🕹️ Controls

| Action | Control |
|---|---|
| Move | Arrow keys or W, A, S, D |
| Mouse/touch movement | Move or drag on the game screen |
| Pause/Resume | P or Esc |
| Shoot | Automatic |

## 🛠️ Technologies Used

- **HTML5** — Game structure and canvas
- **CSS3** — Styling, layout, and visual effects
- **JavaScript** — Game logic, enemies, collisions, scoring, and controls
- **Git** — Version control
- **GitHub** — Source code hosting and collaboration

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Click **Start game** and defend the galaxy!
